---
title: "Update an Existing Product in the TuKit Marketplace"
sidebarTitle: "Update Product"
description: "Modify the fields or files of an existing product by its ID. Requires admin level 2 authentication and accepts multipart/form-data with optional file replacements."
---

The Update Product endpoint lets an admin partially or fully overwrite an existing marketplace product. All body fields and file fields are optional — only the values you include are applied, and any file you upload replaces the corresponding stored file on the server. The endpoint first checks that the product exists, then verifies admin level 2 authorization before making any changes. If a numeric `discount` value is supplied, the endpoint automatically recalculates and persists `discountPrice` as `price * (1 - discount / 100)`.

**POST** `/api/product/update/:productId`

---

## Authentication

<Warning>
  Every request must include a valid JWT in the `token-access` header. The
  authenticated user must also hold the **admin level 2** role
  (`name: "admin"`, `value: "2"`). Requests from non-admin users return
  HTTP `203`.
</Warning>

| Header         | Value              | Required |
| -------------- | ------------------ | -------- |
| `token-access` | `<your JWT token>` | ✅ Yes   |

---

## Path Parameters

<ParamField path="productId" type="string" required>
  The MongoDB ObjectId of the product to update. Returned as `_id` when the
  product was created or listed.
</ParamField>

---

## Request Body

This endpoint accepts `multipart/form-data`. All fields are optional; omitted fields retain their existing values.

### Text Fields

<ParamField body="title" type="string">
  New display name for the product.
</ParamField>

<ParamField body="description" type="string">
  New long-form description.
</ParamField>

<ParamField body="category" type="string">
  Product category. Allowed values: `"Uniforme"` | `"Tipografía"`.
</ParamField>

<ParamField body="price" type="number">
  Updated base price. If `discount` is also provided, `discountPrice` is
  recalculated from this value.
</ParamField>

<ParamField body="format" type="string">
  Updated design file format string, e.g. `"AI"`, `"PNG"`, `"PSD"`.
</ParamField>

<ParamField body="typeProduct" type="string">
  Updated payment type. Allowed values: `"Pago"` | `"Gratuito"`.
</ParamField>

<ParamField body="discount" type="string">
  Discount percentage expressed as a numeric string, e.g. `"10"` for a 10%
  discount. When provided alongside `price`, the server calculates
  `discountPrice = price * (1 - discount / 100)` and stores both values.
</ParamField>

### File Fields

Each file field accepts at most **1 file**. Providing a file replaces the existing stored file for that field.

<ParamField body="archivoUrl" type="file">
  Replacement design file. Replaces the previously stored design file.
</ParamField>

<ParamField body="imageUrl" type="file">
  Replacement preview image.
</ParamField>

<ParamField body="shirtGif" type="file">
  Replacement shirt demonstration GIF or image.
</ParamField>

<ParamField body="shortsGif" type="file">
  Replacement shorts demonstration GIF or image.
</ParamField>

## Discount Calculation

<Note>
  When you supply a `discount` string whose numeric value is valid (e.g.
  `"10"`, `"25.5"`) **and** the request also includes a `price` value,
  the server automatically sets:

  ```
  discountPrice = price × (1 − discount / 100)
  ```

  For example, `price=20` and `discount="10"` yields `discountPrice=18`.
  The `discountPrice` field is stored as a `String` in the database.
</Note>

## Error Responses

| Status | Condition                               | `status` |
| ------ | --------------------------------------- | -------- |
| `404`  | No product found with the given ID      | `false`  |
| `203`  | Authenticated user is not admin level 2 | `false`  |
| `500`  | Unexpected server error                 | —        |

```json 404 — Product Not Found
{
  "msj": "Producto no encontrado",
  "status": false
}
```

```json 203 — Not Authorized
{
  "msj": "No estás autorizado para agregar productos",
  "status": false
}
```

## Example

<Note>
  Replace `<YOUR_TOKEN>` with a valid JWT for an admin level 2 user, and
  `<PRODUCT_ID>` with the target product's `_id`.
</Note>

<Tabs>
  <Tab title="Text fields only">
    ```bash cURL
    curl -X POST https://your-api-domain.com/api/product/update/665a1f2e8c4b2a001e3d9f01 \
      -H "token-access: <YOUR_TOKEN>" \
      -F "price=15.99" \
      -F "discount=10" \
      -F "typeProduct=Pago"
    ```
  </Tab>
  <Tab title="With file replacement">
    ```bash cURL
    curl -X POST https://your-api-domain.com/api/product/update/665a1f2e8c4b2a001e3d9f01 \
      -H "token-access: <YOUR_TOKEN>" \
      -F "title=Club Deportivo Tigres 2025 — Edición Especial" \
      -F "price=15.99" \
      -F "discount=10" \
      -F "imageUrl=@/path/to/new-preview.png"
    ```
  </Tab>
</Tabs>
