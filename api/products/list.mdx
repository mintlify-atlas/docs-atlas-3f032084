---
title: "List All Products by Category or Payment Type"
sidebarTitle: "List Products"
description: "Browse all marketplace products filtered by category (uniform vs. typography) or payment type (paid vs. free) with built-in pagination. Requires a valid token-access JWT."
---

TuKit provides two bulk-listing endpoints for browsing the full product catalogue. The first, `get-all-products-uni-typo`, partitions the catalogue by **category** — pass a positive numeric value in `:typeCategory` to receive uniforms, or zero/negative to receive typography products. The second, `get-all-products-payment-free`, partitions by **payment type** — positive returns paid products and zero/negative returns free products. Both endpoints support optional pagination through path parameters handled by the `Paginate` middleware, sort results by newest first (`_id: -1`), and return the same response shape including a `pagination` metadata object.

**POST** `/api/product/get-all-products-uni-typo/:typeCategory/:pag?/:perpage?`

**POST** `/api/product/get-all-products-payment-free/:paymentAndFree/:pag?/:perpage?`

---

## Authentication

<Warning>
  Both endpoints require a valid JWT in the `token-access` header. Standard
  user authentication is sufficient — admin privileges are not required.
</Warning>

| Header         | Value              | Required |
| -------------- | ------------------ | -------- |
| `token-access` | `<your JWT token>` | ✅ Yes   |

---

## Endpoint 1 — List by Category

**POST** `/api/product/get-all-products-uni-typo/:typeCategory/:pag?/:perpage?`

### Path Parameters

<ParamField path="typeCategory" type="number" required>
  Numeric flag that selects the product category to return.

  - **`> 0`** — Returns products where `category = "Uniforme"`.
  - **`≤ 0`** (zero or negative) — Returns products where `category = "Tipografía"`.
</ParamField>

<ParamField path="pag" type="number">
  Page number to retrieve. Processed by the `Paginate` middleware. Optional —
  defaults to page `1` when omitted.
</ParamField>

<ParamField path="perpage" type="number">
  Results per page. Processed by the `Paginate` middleware. Optional — the
  middleware supplies a default when omitted.
</ParamField>

---

## Endpoint 2 — List by Payment Type

**POST** `/api/product/get-all-products-payment-free/:paymentAndFree/:pag?/:perpage?`

### Path Parameters

<ParamField path="paymentAndFree" type="number" required>
  Numeric flag that selects the product payment type to return.

  - **`> 0`** — Returns products where `typeProduct = "Pago"`.
  - **`≤ 0`** (zero or negative) — Returns products where `typeProduct = "Gratuito"`.
</ParamField>

<ParamField path="pag" type="number">
  Page number to retrieve. Optional — defaults to page `1` when omitted.
</ParamField>

<ParamField path="perpage" type="number">
  Results per page. Optional — the middleware supplies a default when omitted.
</ParamField>

---

## Request Body

Neither endpoint requires a request body. Both rely entirely on path parameters.

---

## Response

Both endpoints share an identical response shape.

### 200 — Products Loaded

<ResponseField name="msj" type="string">
  `"Cargando productos..."`
</ResponseField>

<ResponseField name="status" type="boolean">
  `true` on success.
</ResponseField>

<ResponseField name="data" type="array">
  Array of product documents matching the applied filter, sorted by newest
  first. May be empty if no products exist for the selected category or
  payment type.

  <Expandable title="Product item fields">
    <ResponseField name="_id" type="string">MongoDB ObjectId.</ResponseField>
    <ResponseField name="title" type="string">Product title.</ResponseField>
    <ResponseField name="description" type="string">Product description.</ResponseField>
    <ResponseField name="category" type="string">`"Uniforme"` or `"Tipografía"`.</ResponseField>
    <ResponseField name="price" type="number">Base price.</ResponseField>
    <ResponseField name="format" type="string">Design file format.</ResponseField>
    <ResponseField name="typeProduct" type="string">`"Pago"` or `"Gratuito"`.</ResponseField>
    <ResponseField name="archivoUrl" type="array">Design file path entries.</ResponseField>
    <ResponseField name="imageUrl" type="array">Preview image path entries.</ResponseField>
    <ResponseField name="shirtGif" type="array">Shirt GIF path entries.</ResponseField>
    <ResponseField name="shortsGif" type="array">Shorts GIF path entries.</ResponseField>
    <ResponseField name="discount" type="string">Discount label or percentage string.</ResponseField>
    <ResponseField name="discountPrice" type="string">Calculated discounted price string.</ResponseField>
    <ResponseField name="minCant" type="number">Minimum purchase quantity.</ResponseField>
    <ResponseField name="date" type="string">ISO 8601 creation date.</ResponseField>
    <ResponseField name="user" type="object">Creator snapshot `{ _id, userName, email, roles, activate }`.</ResponseField>
    <ResponseField name="createdAt" type="string">Mongoose timestamp.</ResponseField>
    <ResponseField name="updatedAt" type="string">Mongoose timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata for the current result set.

  <Expandable title="Pagination fields">
    <ResponseField name="pag" type="string | number">
      The current page number as passed in the path parameter.
    </ResponseField>
    <ResponseField name="perpage" type="number">
      The limit value used for this page (sourced from the `Paginate`
      middleware).
    </ResponseField>
    <ResponseField name="pags" type="number">
      Total number of pages calculated as
      `Math.ceil(totalDocuments / perpage)`.
    </ResponseField>
  </Expandable>
</ResponseField>
